## 📁 Cấu trúc thư mục dự án

```text
├── database/          # Chứa script khởi tạo CSDL và tạo bảng (DDL)
│   └── schema.sql
├── data/              # Chứa script chèn dữ liệu mẫu (DML)
│   └── sample_data.sql
├── queries/           # Chứa các câu truy vấn, câu hỏi bài tập
│   └── solutions.sql
├── docs/              # Tài liệu đề bài, sơ đồ ERD, báo cáo Word/PDF
│   └── README.md
├── .gitignore         # Quy định các file không đẩy lên GitHub
└── README.md          # Giới thiệu dự án
```

---

## 🚀 Hướng dẫn chạy
1. Mở hệ quản trị CSDL (MySQL Workbench / SSMS / PostgreSQL / DBeaver).
2. Chạy script tạo CSDL và bảng: `database/schema.sql`.
3. Chèn dữ liệu mẫu: `data/sample_data.sql`.
4. Thực thi các truy vấn kiểm tra: `queries/solutions.sql`.
